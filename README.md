#

### О программе

Утилита создана для одной простой задачи — скачивать видео и аудио с YouTube. Подобных решений много, но отличительной чертой именно этой утилиты является простой и интуитивно понятный интерфейс.

Для загрузки нужно лишь вставить ссылку на видео, выбрать нужное качество видео/аудио и нажать на СКАЧАТЬ. Также можно скачивать аудио отдельно от видео и наоборот.

> [!Tip]
> Скачивание превью также реализовано — просто кликните ПКМ по изображении и обложка сохранится.

#

### Устройство

Утилита сделана не только максимально удобной, но и максимально легкой, быстрой и без лишних файлов и библиотек. 

Для скачивания видео используется [yt-dlp.exe](https://github.com/yt-dlp/yt-dlp) — популярный CLI загрузчик. 
Для склеивания видео и аудио в один файл [ffmpeg.exe](https://github.com/GyanD/codexffmpeg) — консольная утилита для обработки видео.
Графическая оболочка весит менее 40кб, а кроме нее есть лишь иконка для пункта в контекстном меню.

> В итоге всего четыре файла: yt-dlp.exe, ffmpeg.exe, gui и иконка.

#

### Фишки

Помимо легкости, скорости и портативности есть еще одна интересная фишка — возможность интеграции в контекстное меню.

Установив кастомный пункт можно упростить загрузку роликов и качать их сразу в нужное место. Достаточно лишь скопировать ссылку на видео, перейти в нужную папку и активировать пункт "YTDownloader".
Утилита откроется, сама вставит ссылку и найдет видео. Вам нужно лишь выбрать нужный формат и нажать на СКАЧАТЬ.
